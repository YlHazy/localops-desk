# Goal

Build LocalOps Desk: a local personal operations cockpit that lets a developer/operator configure remote servers, run low-pressure checks, review status and recent incidents, generate a diagnostic report, and expose a safe local API for Codex operations agents.

## Success Criteria

- A local Web MVP starts successfully.
- The UI shows a realistic production/demo server topology.
- The operator can trigger a light check and see updated status.
- The operator can inspect a host detail page, recent check history, and a diagnostic report.
- Actions are dry-run by default and visibly separated from real execution.
- No secrets are stored, displayed, or logged.
