# Page Map

- `/` Dashboard
  - Global health summary
  - Environment lanes
  - Host/service cards
  - Manual light check button
- `/hosts`
  - Host inventory
  - Configuration summary
  - SSH and health endpoint metadata
- `/hosts/:id`
  - Host resource summary
  - Docker/Compose status
  - HTTP/SSH check evidence
  - Recent events
- `/checks`
  - Light/deep/manual check history
  - Duration and failure reasons
- `/actions`
  - Dry-run recovery plans
  - Action risk tier
  - Confirmation boundary
- `/reports`
  - Incident diagnosis
  - Evidence and recommended next step
- `/agent-api`
  - Local API manifest for Codex agents
