# Design Brief

LocalOps Desk should feel like a local operations flight deck: professional, calm, information-dense, and safe.

It should not look like a generic cloud console, a noisy hacker terminal, or a marketing landing page. The first screen is the actual dashboard.

## Visual Direction

- Light operational workspace with a deep navigation rail.
- Restrained status colors.
- Dense but scannable tables and panels.
- Clear evidence for every status.
- Red appears only for true service-impacting incidents.

## Information Architecture

- Status overview.
- Server detail.
- Check history.
- Action dry-run.
- Diagnostic report.
- Agent API.

## First-Viewport Promise

Within five seconds the operator should know:

- Whether production is user-facing healthy.
- Which server or dependency is most suspicious.
- Which safe next action can be previewed.
